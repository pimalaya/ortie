# base64 runs on base64-codec

The base64 crate gave way to base64-codec 0.1, as the family decided on 2026-11-03: src/auth/get.rs encodes the CSRF state and the JWT `jti` through `base64_url` (URL alphabet, unpadded) and decodes a PEM client certificate body through `Base64Codec::decode_vec`, refusing a body it did not read clean since the codec itself never fails. `main` calls `SimdCpu::install_detected()` first (simd-cpu 0.1, `std`), so every codec built afterwards runs the detected backend. The integration tests encode and decode through the codec too, so the base64 crate is no longer a direct dependency; io-oauth, io-proxy and io-pim-discovery still pull it.

Capabilities moved: none.

Verified: `cargo clippy --all-targets --all-features` clean, `cargo test --all-features` passed (the PEM certificate and JWT assertion paths in tests/client_credentials.rs included), `cargo clippy --no-default-features --features rustls-ring` clean.

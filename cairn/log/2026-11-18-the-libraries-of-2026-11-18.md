# The libraries of 2026-11-18

Ortie moved onto pimalaya-config 0.6.0 and pimalaya-cli 0.6.1, released on 2026-11-18, with no [patch]. No Ortie code changed: Ortie builds the secret feature but never matches `SecretError::Output`, the breaking change of pimalaya-config 0.6.0.

## What reaches users

- The text error report sanitizes its message and each cause line by line, so a control character from a message or a file no longer drives the terminal.
- `--log-file` creates the file at 0600 and refuses a symbolic link at its path.
- The manual pages print the version once in their VERSION section.
- A TOML parse error of the configuration no longer prints the source line, and a refused secret no longer echoes its value.
- A secret command that fails is named, with a hint to run it yourself; its output is never printed.

## Capabilities moved

None: these are the libraries' behaviours, which the specs of pimalaya-cli and pimalaya-config state.

## Verified

`cargo test --all-features` and `cargo clippy --all-features --all-targets` pass.
